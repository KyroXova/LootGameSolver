# LootGameSolver - Initial Release (1.0.0)

**Full Changelog**: https://github.com/KyroXova/LootGameSolver/commits/archive/1.0.0-dev

## What's Changed

- Initial framework and package structure setup for `com.kyroxova.lootgamesolver` by @KyroXova
- Minesweeper solver engine with deterministic deduction and probabilistic fallback by @KyroXova
- Sudoku solver integrating standard backtracking algorithms and world board coordinate mapping by @KyroXova
- Game of Light (Simon Says) sequence tracking solver by @KyroXova
- Reflection bridge for LootGames tile entities and structure detection by @KyroXova
- 3D in-world hologram rendering for mine flags, safe cells, Sudoku numbers, and sequence targets by @KyroXova
- Centered 3-row HUD overlay displaying minigame detection status, mode, and keybind states by @KyroXova
- Smooth camera rotation tracking toward target blocks during auto-solve actions by @KyroXova
- Optimistic local grid state management for Sudoku to avoid server sync click desyncs by @KyroXova
- 4-stage continuous Minesweeper auto-solve support by @KyroXova
- Removal of 32-cap hologram rendering limit and depth clipping improvements by @KyroXova
